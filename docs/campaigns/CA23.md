# CA-23 — real ECIA consumption of the causal source

Date: 2026-09-26

CausalGeometry remains upstream.

The dependency direction is

CausalGeometry → ECIA/GenContinuum adapter,

never

ECIA → CausalGeometry kernel.

CA-23 closes only when a real downstream ECIA target instantiates the source
contracts and proves preservation claims with actual target structures.

## 2. Information-loss discipline

For every realization R define the source indistinguishability relation

X ~_R Y  iff  R(X) ≃ R(Y)

with the target notion of equivalence stated explicitly.

For a comparison R → S, information loss must be represented by inclusion or
factorization of these relations only when proved.

The campaign must publish a matrix recording for each consumer:

- source data observed;
- source data forgotten;
- whether the map is faithful on a named domain;
- whether it is conservative on a named class of morphisms;
- whether a reconstruction map exists;
- whether the comparison is equivalence, quotient/loss, completion,
  localization, analytic upgrade or conditional bridge.

No claim of "same structural number" may be inferred merely from equality of
one numerical shadow.

### Composition up to target equivalence

The source now distinguishes strict target equality from categorical
preservation up to a downstream equivalence.

`PreservesCompositeUpTo` and `PreservesCompositionSystemUpTo` accept the
target equivalence explicitly. If a numerical shadow is invariant under that
equivalence, `targetShadow_comp_upTo` derives multiplicativity without
forcing categorical ECIA multiplication to become literal equality.

This is the form required by the real GenContinuum structural-number target,
where finite external products are canonically isomorphic to the corresponding
finite numeral rather than definitionally equal.

## 3. Phi/Psi preservation

ECIA must consume Phi and Psi separately.

At the differential level it must state whether

d_E Phi = Phi d_C

and

d_C Psi = Psi d_E.

At Hodge level it must separately state the delta and Delta defects.

This enables ECIA to preserve one direction while losing the other, which is
a feature of the causal/restriction architecture rather than a failure.

## 4. Cohomology/Hodge consumption

For every supported degree n the adapter must choose target carriers

H_E^n(RX)

and, where Hodge is available,

Harm_E^n(RX).

It must then prove the relevant linear/additive equivalences.

When the source Hodge representation is proved, the adapter can derive

H_C^n(X) ≃ Harm_E^n(RX).

This must not be reversed into a statement that every ECIA harmonic state has
a causal interpretation outside the named realization domain.

## 5A. Atomic versus cyclic primitive boundary

The source now exposes `ECIAPrimitiveFactorizationContract.lean`.

This contract keeps three logically distinct statements separate:

- source irreducibility implies target cyclic primitiveness;
- target cyclic primitiveness implies source irreducibility;
- both directions hold and therefore give an iff on a named realization.

Each direction requires its own reflection hypotheses from the CA-22 bridge.
Preservation of primitive counts, traces or an Ihara signature does not by
itself discharge those hypotheses.  This is the source-side barrier against
identifying compositional atoms with primitive closed/cyclic classes merely
because their decategorified numerical shadows agree.

The new source contract does not close CA-23.20.  Closure still requires an
actual ECIA/GenContinuum consumer to instantiate the carrier, monoid hom,
comparison square and reflection proofs downstream.

## 5B. Downstream filtration Phi/Psi consumer

The downstream GenContinuum branch `campaign/causal-ecia-adapter` now reuses
`GrowingFiltration.map` and `GrowingFiltration.comap` as a concrete
realization of the causal pair.

For a ring homomorphism `f` the adapter proves

[
\Phi(P)=f(P),\qquad \Psi(Q)=f^{-1}(Q),
]

with the image interpreted literally as set image. The existing
`map_level_le_iff_le_comap_level` theorem realizes the optional adjunction
degree by degree.

Crucially the adapter does not infer inverse laws. It proves the exact
boundaries:

- `Psi Phi = id` on every source subset iff `f` is injective;
- `Phi Psi = id` on every target subset iff `f` is surjective;
- both round trips are identities iff `f` is bijective.

This is downstream implementation evidence, not yet accreditation:
CA-23.31 still requires exact-SHA typechecks in both repositories.

## 5C. Admissibility-scoped cohomology and Hodge

The source contracts now match the partial nature of real ECIA realizations.

`PreservesCausalCohomologyOnAdmissible` requires H¹/H² equivalences only
when `sourceAdmissible X` holds. Likewise,
`PreservesCausalHodgeH1OnAdmissible` requires source Hodge data,
representation and harmonic equivalence only on that named source domain.

The older global contracts remain stronger special cases and convert
canonically to the scoped versions.

The downstream GenContinuum campaign also contains a finite nontrivial control:
the rational causal Hodge model with one-dimensional H¹ is linearly
equivalent to the existing one-dimensional rational Tate target. This proves
that the comparison mechanism is realizable without promoting ECIA's still
open absolute/global H¹ programme.

## 5D. ECIA rose stable Ihara control

The downstream ECIA adapter now packages the already existing one-loop rose as
one `FiniteIharaSignature` and proves that its causal trace series,
determinant polynomial and Euler zeta are the existing ECIA Hashimoto/Ihara

The comparison is theorem-level:

- causal trace sequence = ECIA matrix-power trace;
- causal period-one primitive multiplicity = the two oriented primitive rose

- integral determinant polynomial maps to ECIA's rational rose denominator;
- causal Euler zeta = ECIA determinant zeta = ECIA Euler product.

This is a nontrivial cross-library control for CA-23.19--21. It is not yet a
full realization contract on causal numbers: that last step requires a named

## 5E. Scoped strong Laplacian contract and finite spectral control

The strong operator contract now also has an admissibility-scoped form,
`PreservesGradedCausalLaplacianOnAdmissible`.  It requires, only on the
declared source domain:

- a source graded cochain complex and Hodge package;
- a target cochain carrier and target Laplacian;
- a linear cochain equivalence;
- an operator intertwining equation.

Harmonic and arbitrary eigenspace equivalences are derived from that equation.

The downstream GenContinuum campaign supplies a finite operator-level control.
The causal rational Hodge control has degree-one Laplacian

[
(x,y)\mapsto(x,0).
]

It is intertwined with the genuine Tate matrix morphism
(operatorname{diag}(1,0)) on the two-dimensional object of
`TateDerivedTarget`.  The target matrix is transpose-self-adjoint, survives
the faithful passage to the native derived category, and induces equivalent
eigenspaces for every rational eigenvalue.  Its zero eigenspace recovers the
same one-dimensional Tate line used by the finite H¹ bridge.

This is a non-circular finite spectral control.  It does not promote ECIA's
global Green operator, absolute H¹ or exact Riemann spectral identification.

## 5G. Concrete adversarial loss controls

Two downstream controls now exercise the loss discipline rather than merely
state it.

First, the source adds `Models.EmptyBoundaryComposition`, a deliberately
coarse negative-control composition system on empty boundary.  Composition is
the disjoint union of event systems.  Its selected equivalence is explicitly
indiscrete and is used only as a mutation control.  The empty-event and
singleton-event diaries are proved distinct.

GenContinuum equips this control with the constant multiplicative shadow one.
The ordinary arithmetic adapter laws still hold, but the two distinct diaries
have equal shadow, equal finite ECIA realization and equivalent targets.
`constantOne_adapter_not_faithful` proves the adapter is not faithful.
Thus a multiplicative numerical shadow cannot certify preservation of richer
causal structure.

Second, `PhiPsiDirectionalControls` supplies two exact algebraic
discriminators:

- constants `Q -> Q[X]` is injective and not surjective, so `Psi Phi` is
  identity on all source subsets while `Phi Psi` is not identity on all
  target subsets;
- evaluation at zero `Q[X] -> Q` is surjective and not injective, so the
  target round trip is identity while the source round trip is not.

These controls implement CA-23.29 and CA-23.30 at theorem level.  Validation
remains fail-closed until CA-23.31 runs against the pinned cross-repository
SHAs.

## 5I. Joint conservativity versus reconstruction

The indexed-family API now keeps two levels distinct.

`JointlyConservative R` is a proposition saying that equality of every local
observation reflects equality of source objects.

`IndexedRealizationFamily.Reconstruction R` is stronger evidence: it stores
an actual recovery function from the complete dependent local packet together
with a left-inverse law. The source proves

    Reconstruction R -> JointlyConservative R

and deliberately does not manufacture reconstruction from conservativity by
classical choice.

`Models.IndexedFamilyControls` supplies an explicit reconstruction of the
two-coordinate family and proves that the collapsed one-coordinate mutation
admits no reconstruction because it is not jointly conservative.

`Models.CommonSourceControls` additionally supplies a named two-element
domain of actual `CausalNumber Unit` values and a two-place family that is
jointly conservative on that domain, together with a collapsed family that
forgets the distinguishing source coordinate.

This provides theorem-level controls for CA-23.27--28 and a non-elliptic
common-source precursor for CA-24.14.  It does not yet claim that the Néron
family reconstructs its causal source.

## 5J. Strict information-loss order

The indexed-realization API now contains theorem-level information ordering.

A `Comparison R S` is a placewise map from the richer family `R` to the
target family `S` commuting with realization. It induces a map of complete
packets and propagates collapse from `R` to `S`.

`StrictLossWitness eta` strengthens this with two distinct source objects
which the target family collapses everywhere while the richer family still
separates. From such a witness the source derives:

- the target family is not jointly conservative;
- the target family admits no explicit `Reconstruction`.

Conversely, if a lossier target carries explicit reconstruction, that
reconstruction pulls back along the comparison to the richer family. Thus
reconstruction respects the information order in the only sound direction.

The Tamagawa control instantiates this order concretely: quotient-map
observations distinguish two sources while the bare index family sends both to
2. This is a strict structural-to-numerical loss, not merely a warning that
cardinalities can coincide.

## 5K. Native ECIA primitive-word bridge

The downstream GenContinuum campaign now connects the source compositional
atom notion to the cyclic primitive notion actually used by ECIA.

For the free one-direction causal-length monoid, a source element of length
(n) is realized as the unary ECIA word with (n) copies of the unique
letter. The downstream theorem proves

[
operatorname{Irreducible}(x)
iff
operatorname{IsPrimitiveWord}(operatorname{unaryWord}(x)).
]

The unique causal atom therefore maps to a native ECIA primitive word and its
cyclic closure is a native `IsPrimitiveCycle`. Length two is an explicit
negative control: it is compositionally reducible and its unary word is not
primitive.

This result is stronger than comparing primitive counts: it identifies the two
primitive predicates on a named realization. It remains deliberately narrower
than a universal statement for arbitrary causal domains or arbitrary ECIA
cyclic targets.

Arnés downstream:
`Scratch/CausalPrimitiveWordBridgeAudit.lean`.

## Strong Laplacian/spectral contract

ECIASpectralContract.lean strengthens the source-side boundary beyond an
arbitrary equivalence of harmonic carriers.  A downstream ECIA consumer must
supply, degree by degree:

- a target cochain carrier;
- a target Laplacian;
- a linear equivalence between source and target cochains;
- a proof that the equivalence intertwines the source causal Laplacian with
  the target Laplacian.

From those data CausalGeometry derives automatically:

- equivalence of harmonic spaces;
- equivalence of every lambda-eigenspace;
- equality of finite eigenspace multiplicities.

Thus "ECIA preserves the spectrum" cannot be asserted by naming equal lists of
numbers.  It must descend from an actual operator-level intertwiner.  A real
downstream instantiation is still required before any CA-23 preservation row
is accredited.

# Exit criteria

A source-side Prop named "Preserves..." is not CA-23 evidence by itself.

CA-23 requires a real target instantiation, proofs in the downstream
repository, exact-SHA evidence, and an information-loss audit.
