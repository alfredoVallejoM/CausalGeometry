# CA-23 — real ECIA consumption of the causal source

Date: 2026-09-26

CausalGeometry remains upstream.

The dependency direction is

CausalGeometry → ECIA/GenContinuum adapter,

never

ECIA → CausalGeometry kernel.

CA-23 closes only when a real downstream ECIA target instantiates the source
contracts and proves preservation claims with actual target structures.

## 1. Source contracts already available

The source now exposes independent contracts for:

- admissibility;

- arbitrary-degree abstract causal cohomology;
- arbitrary positive-degree abstract causal Hodge structure.

The most recent arbitrary-degree interfaces are in
CausalGeometry/Realization/ECIAGradedContract.lean.

These contracts intentionally do not force one monolithic
"ECIA-preserves-everything" record.  Every mathematical preservation claim
must be proved separately.

## 2. Information-loss discipline

For every realization R define the source indistinguishability relation

X ~_R Y  iff  R(X) ≃ R(Y)

with the target notion of equivalence stated explicitly.

For a comparison R → S, information loss must be represented by inclusion or
factorization of these relations only when proved.

The campaign must publish a matrix recording for each consumer:

- source data observed;
- source data forgotten;
- whether the map is faithful on a named domain;
- whether it is conservative on a named class of morphisms;
- whether a reconstruction map exists;
- whether the comparison is equivalence, quotient/loss, completion,
  localization, analytic upgrade or conditional bridge.

No claim of "same structural number" may be inferred merely from equality of
one numerical shadow.

## 3. Phi/Psi preservation

ECIA must consume Phi and Psi separately.

At the differential level it must state whether

d_E Phi = Phi d_C

and

d_C Psi = Psi d_E.

At Hodge level it must separately state the delta and Delta defects.

This enables ECIA to preserve one direction while losing the other, which is
a feature of the causal/restriction architecture rather than a failure.

## 4. Cohomology/Hodge consumption

For every supported degree n the adapter must choose target carriers

H_E^n(RX)

and, where Hodge is available,

Harm_E^n(RX).

It must then prove the relevant linear/additive equivalences.

When the source Hodge representation is proved, the adapter can derive

H_C^n(X) ≃ Harm_E^n(RX).

This must not be reversed into a statement that every ECIA harmonic state has
a causal interpretation outside the named realization domain.

## 5. Cyclic/local compatibility

The existing stable Ihara profile gives a particularly strong first consumer:

one source may simultaneously carry

- q=p^f local provenance;
- finite quotient size;
- Hashimoto state/NNZ data;
- primitive conjugacy spectrum;
- trace sequence;
- determinant;
- Euler zeta;
- Ihara equality.

ECIA should preserve this as one typed package before attempting global
spectral upgrades.

## 5A. Atomic versus cyclic primitive boundary

The source now exposes `ECIAPrimitiveFactorizationContract.lean`.

This contract keeps three logically distinct statements separate:

- source irreducibility implies target cyclic primitiveness;
- target cyclic primitiveness implies source irreducibility;
- both directions hold and therefore give an iff on a named realization.

Each direction requires its own reflection hypotheses from the CA-22 bridge.
Preservation of primitive counts, traces or an Ihara signature does not by
itself discharge those hypotheses.  This is the source-side barrier against
identifying compositional atoms with primitive closed/cyclic classes merely
because their decategorified numerical shadows agree.

The new source contract does not close CA-23.20.  Closure still requires an
actual ECIA/GenContinuum consumer to instantiate the carrier, monoid hom,
comparison square and reflection proofs downstream.

## Strong Laplacian/spectral contract

ECIASpectralContract.lean strengthens the source-side boundary beyond an
arbitrary equivalence of harmonic carriers.  A downstream ECIA consumer must
supply, degree by degree:

- a target cochain carrier;
- a target Laplacian;
- a linear equivalence between source and target cochains;
- a proof that the equivalence intertwines the source causal Laplacian with
  the target Laplacian.

From those data CausalGeometry derives automatically:

- equivalence of harmonic spaces;
- equivalence of every lambda-eigenspace;
- equality of finite eigenspace multiplicities.

Thus "ECIA preserves the spectrum" cannot be asserted by naming equal lists of
numbers.  It must descend from an actual operator-level intertwiner.  A real
downstream instantiation is still required before any CA-23 preservation row
is accredited.

# Exit criteria

A source-side Prop named "Preserves..." is not CA-23 evidence by itself.

CA-23 requires a real target instantiation, proofs in the downstream
repository, exact-SHA evidence, and an information-loss audit.
