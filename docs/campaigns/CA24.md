# CA-24 — advanced arithmetic and geometric realization campaign

Date: 2026-09-26

CA-24 expands the typed realization family after the graph/Ihara and local
Bruhat--Tits layers are stable.

The rule is strict:

a target name is never used as a definition of a causal source object.

Every target is introduced by a typed realization plus explicit comparison
theorems recording what is preserved and what is lost.

## 1. Priority order

The recommended order is:

1. finite-field point count and Frobenius;
2. local Hecke correspondences;
3. Tate/lattice and adelic assembly;
4. Galois and Weil--Deligne packets;
5. Schreier/dessin/F1 controlled combinatorial losses;
6. p-adic Hodge comparisons under their real hypotheses;
7. automorphic packets and local/global comparison;
8. thermodynamic/operatorial realizations;
9. elliptic/Mordell--Weil/Selmer/Neron realizations.

This order reuses the strongest source machinery already present:
restriction towers, local q-data, finite graphs, primitive cycles,
cohomology and transfer determinants.

## 2. Frobenius and point counting

A finite-field realization must contain an actual target object over F_q and an
actual Frobenius endomorphism.

The source comparison target is not "Frobenius by analogy" but a theorem
relating one causal/local endocorrespondence to the target Frobenius action.

Point-count identities are target theorems.

The expected chain is

finite causal restriction data
→ finite-field realization
→ Frobenius action
→ trace on supported cohomology
→ point-count comparison.

No trace formula may be used backwards to define the source correspondence.

## 3. Hecke realization

The q+1 local projective/lattice star provides the combinatorial input for a
local correspondence.

CA-24 must distinguish:

- adjacency/finite correspondence;
- Hecke operator on a chosen function/module space;
- spherical Hecke algebra;
- Satake parameter;
- automorphic representation.

Only the first item is close to the present source. Each later upgrade needs
its own target structure and theorem.

## 4. Tate and adelic realization

The causal arithmetic layer already carries valuations, completion data and
fractions in supported sectors.

The Tate/lattice realization should send a source scale/fraction to an actual
lattice object and prove compatibility with multiplication and valuations.

The adelic realization is then a restricted product of local realizations of
one common source.  A tuple of unrelated local objects is not an adelic
unification.

## 5. Galois and Weil--Deligne

Galois representations belong only to source objects with a proved
arithmetic-geometric realization.

A local Weil--Deligne packet must explicitly track:

- inertia;
- Frobenius;
- monodromy N;
- conductor;
- determinant/character where relevant.

The packet comparison must preserve exactly the metadata used later by
L-factors and epsilon factors.

## 6. Schreier, dessins and F1

These are controlled combinatorial realizations.

Each must publish an information-loss theorem.

A formal q→1 slogan is not an F1 realization.  An F1 skeleton must be a typed
target with a proved map from richer coefficient data.

## 7. p-adic Hodge

Crystalline, semistable and de Rham comparisons are conditional on their real
target hypotheses.

No source interface may automatically label a representation crystalline or
semistable.

## 8. Operatorial/thermodynamic

The source can provide:

- weak composition;
- dagger;
- arithmetic length;
- primitive dynamics;
- local/global scaling data.

A Hilbert/operator realization must separately prove

pi(X^dagger)=pi(X)^*

and any energy=length relation.

KMS, modular flow and Tomita--Takesaki are analytic target structures and
remain separate until their hypotheses are discharged.

## 9. Elliptic and local-global arithmetic

The causal source can organize:

- iteration/actions;
- local restriction channels;
- compatible local fibers;
- globalization residuals.

It does not call those objects Mordell--Weil, Selmer or Sha until comparison
theorems identify them with the classical arithmetic objects.

# Exit criteria

CA-24 is a realization campaign, not a list of names.

Every closed row needs:

- a concrete target carrier;
- a source domain;
- a typed realization;
- preservation/loss theorem;
- exact dependency hypotheses;
- positive and mutation controls;
- exact-SHA evidence.
