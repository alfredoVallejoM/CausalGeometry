# CA-05 -- CA-08 atomic obligations

| CA-05.11 | Prove the retract equation \(\chi(\iota(n))=n\). |

| CA-05.14 | Prove the arithmetic shadow is surjective onto the selected positive-integer domain. |
| CA-05.15 | Prove the arithmetic shadow is not faithful. |
