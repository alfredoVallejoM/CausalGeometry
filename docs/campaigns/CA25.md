# CA-25 — analytic and spectral operator closure

Date: 2026-09-26

CA-25 is intentionally downstream of the finite/formal determinant and Ihara
theory.

The repository already has strong finite algebra:

primitive histories
→ primitive counts
→ trace sequences
→ finite Hashimoto matrices
→ determinant power series
→ Euler zeta
→ concrete finite Ihara identity.

None of those finite statements is by itself an infinite-dimensional
Fredholm/spectral theorem.

CA-25 builds the missing analytic layer without circularly importing a target
zeta function as the operator determinant it is meant to explain.

## 1. Functional-analytic carrier

The first task is to construct an independently motivated completed state
space.

For every operator one must record:

- ambient normed/Hilbert/Banach space;
- domain if unbounded;
- closedness/closability;
- adjoint domain;
- boundedness or resolvent information;
- compact/trace-class/nuclear properties where claimed.

A formal matrix family is not automatically an operator on an infinite
completion.

## 2. Trace and determinant

The finite identity

det(I-uT)^(-1)

has an analytic analogue only after the relevant trace-class/Fredholm
hypotheses.

CA-25 must prove the convergence/domain statements needed for

log det(I-uT)^(-1)
  = sum_(n>=1) Tr(T^n) u^n/n

in its actual domain.

If regularized determinants are needed, the regularizer and its nonvanishing
properties must be explicit.

## 3. Local-to-global spectral assembly

Local finite factors may be assembled only after proving:

- convergence of the Euler/restricted product;
- compatibility of local normalizations;
- conductor/epsilon bookkeeping;
- control of bad places;
- analytic continuation when claimed.

No finite local Ihara factor proves a global Riemann-type statement.

## 4. Symmetry and positivity

A critical-line argument requires independent input.

Possible source/target mechanisms include:

- dagger/adjoint symmetry;
- duality;
- functional equation;
- positive pairing/polarization;
- Weil-type quadratic form;
- self-adjoint or normal spectral realization.

CA-25 must prove the mechanism actually used.

A formal symmetry s ↔ 1-s without positivity does not imply a critical-line
zero theorem.

## 5. RH/BSD/Langlands boundaries

The following remain open endpoints unless the actual missing theorem is
proved:

- global Riemann RH;
- general automorphic GRH;
- general BSD;
- Bloch--Kato;
- ETNC;
- general Langlands functoriality.

CausalGeometry may organize common source objects and comparison obligations,
but it must not convert those conjectures into source axioms.

# Exit criteria

CA-25 cannot be closed by finite determinant identities, numerical zero plots
or a conditional theorem whose assumptions already contain the desired global
analytic identification.

Closure is theorem-indexed and may remain partial indefinitely.
