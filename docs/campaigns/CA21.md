# CA-21 — graded causal geometry closure

Date: 2026-09-26

This campaign is additive. It does not replace CA00--CA20 and it does not
reinterpret the primitive ontology.

The architectural direction remains

primitive events
→ configurations/histories
→ paired structural transport (Phi,Psi)
→ optional adjunctions
→ causal differential geometry
→ typed realizations
→ ECIA consumers.

The core design rule is unchanged:

Phi and Psi are independent primitive directions.

No inverse law, adjunction, dagger identification, duality, metric
compatibility, cochain naturality or Hodge compatibility is inherited merely
from the existence of the pair.

## A. Graded causal differential

The previous concrete event complex had the shape

C^0 --d0--> C^1 --d1--> C^2.

CA-21 introduces an abstract nonnegative complex

C^0 --d0--> C^1 --d1--> C^2 --d2--> ...

with

d_(n+1) d_n = 0

for every n.

Positive-degree cohomology is

H^(n+1) = ker(d_(n+1)) / im(d_n),

while

H^0 = ker(d_0).

This is now implemented in
CausalGeometry/Calculus/GradedComplex.lean.

## B. Differential defects of Phi and Psi

For a degree-preserving transport F from A to B define

D_d(F)_n = d_B,n F_n - F_(n+1) d_A,n.

F is a cochain map iff D_d(F)_n=0 for every n.

For composable F and G the exact defect Leibniz law is

D_d(GF) = D_d(G) F + G D_d(F).

For a paired transport (Phi,Psi),

D_d(Psi Phi)
  = D_d(Psi) Phi + Psi D_d(Phi),

D_d(Phi Psi)
  = D_d(Phi) Psi + Phi D_d(Psi).

These formulas are important because round-trip failure can arise from either
direction independently and cancellations can occur. Vanishing of one
direction never implies vanishing of the other.

Implemented in
CausalGeometry/Calculus/PairedCochainTransport.lean.

## C. Functorial cohomology

If D_d(F)=0 then F maps

closed → closed,
exact → exact,

and therefore descends to H^n.

This is now implemented for H^0 and every positive degree.  Phi and Psi induce
separate cohomology maps only under their own naturality hypotheses.

The cohomological round trips

H(Psi) H(Phi)
and
H(Phi) H(Psi)

remain observable endomorphisms. They are not identities by definition.

Implemented in
CausalGeometry/Calculus/GradedCohomologyTransport.lean.

## D. Graded causal Hodge theory

A graded Hodge datum contains codifferentials

delta_n : C^(n+1) → C^n

and degreewise pairings satisfying the explicit adjoint relation.

The Laplacians are

Delta_0 = delta_0 d_0,

Delta_(n+1)
  = d_n delta_n + delta_(n+1) d_(n+1).

Harmonic spaces are kernels of these operators.

For every positive degree, the representation hypotheses are kept explicit:

1. harmonic implies closed;
2. each closed cochain is exact + harmonic;
3. exact and harmonic intersect only at zero.

Under exactly these hypotheses the source proves

Harmonic^(n+1) ≃ H^(n+1).

This is a theorem, not a field silently built into Hodge data.

Implemented in
CausalGeometry/Calculus/GradedHodge.lean.

## E. Hodge defects of Phi/Psi

Besides D_d there are independent codifferential defects

D_delta(Phi)
  = delta_B Phi - Phi delta_A,

D_delta(Psi)
  = delta_A Psi - Psi delta_B,

and Laplacian defects

D_Delta(Phi)
  = Delta_B Phi - Phi Delta_A,

D_Delta(Psi)
  = Delta_A Psi - Psi Delta_B.

The source now proves:

D_d(Phi)=0 and D_delta(Phi)=0
=> D_Delta(Phi)=0,

and symmetrically for Psi.

Consequently a Laplacian-intertwining direction sends harmonic cochains to
harmonic cochains.

Implemented in
CausalGeometry/Calculus/PairedHodgeTransport.lean.

## F. Tensor and metric layer

CA-21 does not identify tensors with one implementation by definition.
Instead it exposes an arbitrary-rank typed interface T^(p,q) with

- tensor product;
- contraction;
- contravariant permutations;
- covariant permutations;
- tensor-product naturality;
- contraction naturality.

A concrete TensorProduct realization is a separate theorem target.

Implemented interface:
CausalGeometry/Calculus/GeneralTensor.lean.

The metric layer currently supplies a symmetric nondegenerate bilinear form

g : V × V → K

without positivity or signature assumptions.

Metric compatibility of a finite causal connection means exact preservation

g(T_e x,T_e y)=g(x,y)

for every enabled primitive event.

The source proves that every such primitive transport is injective.
Surjectivity is deliberately not inferred.

Implemented in
CausalGeometry/Calculus/CausalMetric.lean.

## G. Curvature closure

Already present before CA-21:

- finite curvature as ordered transport defect;
- local gauge-potential curvature;
- gauge covariance;
- exact finite/local comparison under T_e = I + A_e;
- finite Bianchi identity on a causal cube.

CA-21 therefore does not reopen these rows. It extends them toward:

- formal jet comparison;
- asymptotic comparison;
- higher cubical holonomy;
- transport of curvature through Phi/Psi;
- tensorial contractions of curvature.

## H. Variational closure

Finite causal paths now have concatenation.

A local step Lagrangian L assigns a scalar to each enabled primitive event.
The path action is the sum along the derived path.

The source proves

S(p·q)=S(p)+S(q).

For two histories with the same endpoints the variational observable is their
action difference.

For a concurrency diamond the local action-order defect is

[L(C,e)+L(C_e,f)]
-
[L(C,f)+L(C_f,e)].

It changes sign when the diamond orientation is reversed and vanishes exactly
when the two local causal orders have the same action.

Implemented in
CausalGeometry/Variational/DiscreteAction.lean.

Boundary-gauge invariance is also implemented in
CausalGeometry/Variational/ActionGauge.lean:

L' = L + B(C') - B(C)

changes every path action only by B(final)-B(initial), hence action
differences between equal-endpoint paths and the concurrency-square action
defect are invariant.

The next theorem targets are discrete Euler--Lagrange, genuine symmetry
actions, momentum data, Noether and singular/Dirac constraints.

## I. Arbitrary event cubes and raw cubical differential

`EventCube.lean` now defines an n-dimensional causal event cube as a
configuration carrying a `Fin n` family of pairwise concurrent primitive
events.

For every direction it constructs:

- a lower face by deleting the direction;
- an upper face by executing the direction and then deleting it;
- a proof that both faces retain the same ordered surviving event family.

`CubicalCochain.lean` defines raw degree-n scalar cochains and the signed
cubical coboundary

dω(Q) = Σ_i (-1)^i (ω(∂⁺_i Q) - ω(∂⁻_i Q)).

The source also proves that d₀ on a one-event cube is exactly the
previously implemented `causalDifference`. Thus the graded extension is
backward-compatible with the original first-variation calculus.

The remaining hard theorem is the general cubical d²=0, which must be
derived from double-face identities and concurrency endpoint equality
rather than assumed.

# Exit criteria

CA-21 is not closed merely because the new interfaces exist.

Closure requires all of the following:

1. exact SHA typechecks under the local runner;
2. root import closure includes every new Lean module;
3. no forbidden proof shortcuts;
4. positive and mutation controls for independent Phi/Psi defects;
5. arbitrary-degree event realization, not only an abstract graded carrier;
6. cohomology identity/composition laws;
7. a concrete arbitrary-rank tensor realization;
8. adversarial review of Hodge assumptions;
9. resource ledger for finite cubical cochains and tensor operations;
10. downstream ECIA consumer evidence for the rows claimed by CA-23.

Until those conditions are met the correct state is SOURCE-IN-PROGRESS, not
campaign-accredited.
