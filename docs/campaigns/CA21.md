# CA-21 — graded causal geometry closure

Date: 2026-09-26

This campaign is additive. It does not replace CA00--CA20 and it does not
reinterpret the primitive ontology.

The architectural direction remains

primitive events
→ configurations/histories
→ paired structural transport (Phi,Psi)
→ optional adjunctions
→ causal differential geometry
→ typed realizations
→ ECIA consumers.

The core design rule is unchanged:

Phi and Psi are independent primitive directions.

No inverse law, adjunction, dagger identification, duality, metric
compatibility, cochain naturality or Hodge compatibility is inherited merely
from the existence of the pair.

## A. Graded causal differential

The previous concrete event complex had the shape

C^0 --d0--> C^1 --d1--> C^2.

CA-21 introduces an abstract nonnegative complex

C^0 --d0--> C^1 --d1--> C^2 --d2--> ...

with

d_(n+1) d_n = 0

for every n.

Positive-degree cohomology is

H^(n+1) = ker(d_(n+1)) / im(d_n),

while

H^0 = ker(d_0).

This is now implemented in
CausalGeometry/Calculus/GradedComplex.lean.

## B. Differential defects of Phi and Psi

For a degree-preserving transport F from A to B define

D_d(F)_n = d_B,n F_n - F_(n+1) d_A,n.

F is a cochain map iff D_d(F)_n=0 for every n.

For composable F and G the exact defect Leibniz law is

D_d(GF) = D_d(G) F + G D_d(F).

For a paired transport (Phi,Psi),

D_d(Psi Phi)
  = D_d(Psi) Phi + Psi D_d(Phi),

D_d(Phi Psi)
  = D_d(Phi) Psi + Phi D_d(Psi).

These formulas are important because round-trip failure can arise from either
direction independently and cancellations can occur. Vanishing of one
direction never implies vanishing of the other.

Implemented in
CausalGeometry/Calculus/PairedCochainTransport.lean.

## C. Functorial cohomology

If D_d(F)=0 then F maps

closed → closed,
exact → exact,

and therefore descends to H^n.

This is now implemented for H^0 and every positive degree.  Phi and Psi induce
separate cohomology maps only under their own naturality hypotheses.

The cohomological round trips

H(Psi) H(Phi)
and
H(Phi) H(Psi)

remain observable endomorphisms. They are not identities by definition.

Implemented in
CausalGeometry/Calculus/GradedCohomologyTransport.lean.

## D. Graded causal Hodge theory

A graded Hodge datum contains codifferentials

delta_n : C^(n+1) → C^n

and degreewise pairings satisfying the explicit adjoint relation.

The Laplacians are

Delta_0 = delta_0 d_0,

Delta_(n+1)
  = d_n delta_n + delta_(n+1) d_(n+1).

Harmonic spaces are kernels of these operators.

For every positive degree, the representation hypotheses are kept explicit:

1. harmonic implies closed;
2. each closed cochain is exact + harmonic;
3. exact and harmonic intersect only at zero.

Under exactly these hypotheses the source proves

Harmonic^(n+1) ≃ H^(n+1).

This is a theorem, not a field silently built into Hodge data.

Implemented in
CausalGeometry/Calculus/GradedHodge.lean.

## E. Hodge defects of Phi/Psi

Besides D_d there are independent codifferential defects

D_delta(Phi)
  = delta_B Phi - Phi delta_A,

D_delta(Psi)
  = delta_A Psi - Psi delta_B,

and Laplacian defects

D_Delta(Phi)
  = Delta_B Phi - Phi Delta_A,

D_Delta(Psi)
  = Delta_A Psi - Psi Delta_B.

The source now proves:

D_d(Phi)=0 and D_delta(Phi)=0
=> D_Delta(Phi)=0,

and symmetrically for Psi.

Consequently a Laplacian-intertwining direction sends harmonic cochains to
harmonic cochains.

Implemented in
CausalGeometry/Calculus/PairedHodgeTransport.lean.

## F. Tensor and metric layer

CA-21 does not identify tensors with one implementation by definition.
Instead it exposes an arbitrary-rank typed interface T^(p,q) with

- tensor product;
- contraction;
- contravariant permutations;
- covariant permutations;
- tensor-product naturality;
- contraction naturality.

A concrete TensorProduct realization is a separate theorem target.

Implemented interface:
CausalGeometry/Calculus/GeneralTensor.lean.

The metric layer currently supplies a symmetric nondegenerate bilinear form

g : V × V → K

without positivity or signature assumptions.

Metric compatibility of a finite causal connection means exact preservation

g(T_e x,T_e y)=g(x,y)

for every enabled primitive event.

The source proves that every such primitive transport is injective.
Surjectivity is deliberately not inferred.

Implemented in
CausalGeometry/Calculus/CausalMetric.lean.

## G. Curvature closure

Already present before CA-21:

- finite curvature as ordered transport defect;
- local gauge-potential curvature;
- gauge covariance;
- exact finite/local comparison under T_e = I + A_e;
- finite Bianchi identity on a causal cube.

CA-21 therefore does not reopen these rows. It extends them toward:

- formal jet comparison;
- asymptotic comparison;
- higher cubical holonomy;
- transport of curvature through Phi/Psi;
- tensorial contractions of curvature.

## H. Variational closure

Finite causal paths now have concatenation.

A local step Lagrangian L assigns a scalar to each enabled primitive event.
The path action is the sum along the derived path.

The source proves

S(p·q)=S(p)+S(q).

For two histories with the same endpoints the variational observable is their
action difference.

For a concurrency diamond the local action-order defect is

[L(C,e)+L(C_e,f)]
-
[L(C,f)+L(C_f,e)].

It changes sign when the diamond orientation is reversed and vanishes exactly
when the two local causal orders have the same action.

Implemented in
CausalGeometry/Variational/DiscreteAction.lean.

Boundary-gauge invariance is also implemented in
CausalGeometry/Variational/ActionGauge.lean:

L' = L + B(C') - B(C)

changes every path action only by B(final)-B(initial), hence action
differences between equal-endpoint paths and the concurrency-square action
defect are invariant.

The next theorem targets are discrete Euler--Lagrange, genuine symmetry
actions, momentum data, Noether and singular/Dirac constraints.

## I. Arbitrary event cubes and raw cubical differential

`EventCube.lean` now defines an n-dimensional causal event cube as a
configuration carrying a `Fin n` family of pairwise concurrent primitive
events.

For every direction it constructs:

- a lower face by deleting the direction;
- an upper face by executing the direction and then deleting it;
- a proof that both faces retain the same ordered surviving event family.

`CubicalCochain.lean` defines raw degree-n scalar cochains and the signed
cubical coboundary

dω(Q) = Σ_i (-1)^i (ω(∂⁺_i Q) - ω(∂⁻_i Q)).

The source also proves that d₀ on a one-event cube is exactly the
previously implemented `causalDifference`. Thus the graded extension is
backward-compatible with the original first-variation calculus.

The remaining hard theorem is the general cubical d²=0, which must be
derived from double-face identities and concurrency endpoint equality
rather than assumed.

### Arbitrary-dimensional cubical closure

The source now proves all four face-exchange identities for lower/upper faces
in every dimension.  They are unified as `CausalEventCube.face_face`.

The ordered-pair involution

`(i,j) ↦ (i.succAbove j, j.predAbove i)`

reverses deletion order, has no fixed point, preserves the geometric
four-face expression and reverses its alternating sign.  This proves the
all-degree theorem `CausalCubicalCochain.differential_squared` and packages
the result as `gradedCubicalComplex`.

The old 0--1--2 complex is linked back by explicit linear equivalences:

- configuration observables ≃ degree-zero cubical cochains;
- `CausalOneForm` ≃ degree-one cubical cochains;
- `RawTwoCochain` ≃ degree-two cubical cochains.

Under these equivalences the old `d0Linear` and `d1Linear` commute exactly
with cubical `differential 0` and `differential 1`.

## J. Cubical Serre product and relative cohomology

The first front/back construction has been deliberately demoted to
`orderedCup`: it is one chronological Serre-diagonal summand, not the full
higher cup product.

`CubicalShuffleCup.lean` now defines finite ((p,q))-shuffles as coordinate
permutations preserving the internal order of the p- and q-blocks.  For each
shuffle it:

- reindexes the causal event cube;
- evaluates the ordered front/back summand;
- multiplies by the inversion/Koszul sign.

The full product is the finite sum over all such shuffles:

[
  \alpha \smile \beta
  =
  \sum_{\sigma\in Sh(p,q)}
  (-1)^{\mathrm{inv}(\sigma)}
  \operatorname{orderedCup}_{p,q}
  (\alpha,\beta;\sigma Q).
]

The all-degree Leibniz defect is an explicit cochain

[
D_{\smile}(\alpha,\beta)
=
d(\alpha\smile\beta)
-
(d\alpha)\smile\beta
-
(-1)^p\alpha\smile(d\beta).
]

It is **not** declared zero by definition.  The remaining theorem is the
shuffle/face cancellation proving its vanishing.

A same-type low-degree control proves that the unique ((0,0))-shuffle
reduces the full Serre cup to the ordered product and hence recovers the
existing finite causal product rule.

`RelativeCohomology.lean` also constructs the relative complex of any natural
restriction-like graded transport as the degreewise kernel.  Naturality proves
that (d) preserves that kernel, giving relative (H^0) and all positive
relative (H^n).  Forward/Phi-relative and backward/Psi-relative theories are
kept distinct.  The connecting morphism and long exact sequence remain a
separate theorem layer.

### Exterior alternating submodule

`CubicalExterior.lean` now distinguishes raw ordered cubical cochains from
genuine exterior cochains.  A degree-n cochain is alternating when swapping
any two distinct primitive-event axes negates its value.  These alternating
cochains form a K-submodule.

Degrees zero and one are proved automatically alternating; hence the existing
`CausalOneForm` carrier maps canonically into exterior degree one through the
previous cubical linear equivalence.

The next obligations are to prove that the cubical differential preserves this
submodule in every degree and to identify degree-two alternation with the old
`CausalTwoForm.skew` interface.

### Relative short exactness

For a natural restriction-like graded map F, relative cochains are
`ker(F_n)`.  The source now proves degreewise:

- relative inclusion is injective;
- its range is exactly `ker(F_n)`;
- if F is degreewise surjective, the sequence
  `0 → C_rel^n → C^n → D^n → 0`
  is short exact.

The connecting cohomology morphism and the resulting long exact sequence are
still intentionally separate theorem obligations.

### Variational symmetry and action-level Noether

`PathEquivariance.lean` now transports complete causal paths through a
primitive `EventSystemEquiv` and proves path length is invariant.

`CausalSymmetry.lean` pulls step Lagrangians back along the same primitive
equivalence and proves naturality of the complete path action.  A self
equivalence preserving the Lagrangian is therefore a genuine action symmetry.

When the symmetry also fixes both path endpoints, its image becomes a
same-endpoint competitor and the source proves

[
S(Ep)-S(p)=0.
]

This is the first exact Noether-type theorem in the causal variational layer.
It is intentionally action-level: no momentum map or conserved current is
claimed until the required symplectic/tensor data are supplied.

A general `StationaryAgainst` predicate is also present, so Euler--Lagrange
can be formulated by choosing a mathematically justified generating family of
local path variations rather than defining stationarity circularly.

### Complete relative long exact sequence

The relative layer is now closed under a precise split-surjective hypothesis.

Given a natural graded restriction (F:A^\bullet\to B^\bullet) together
with a degreewise linear section, the source constructs:

[
H^0_{rel}\to H^0(A)\to H^0(B)
\xrightarrow{\delta_0} H^1_{rel},
]

and for every positive degree,

[
H^{n+1}_{rel}\to H^{n+1}(A)\to H^{n+1}(B)
\xrightarrow{\delta_n} H^{n+2}_{rel}.
]

The connector is not postulated.  A closed target cochain is lifted through
the section, differentiated, and naturality proves that its differential lands
in the relative kernel.  Exact target representatives are proved to map to
relative exact cochains, so the construction descends through the quotient.

The repository now proves all corresponding exactness identities:

- image relative-to-source = kernel source-to-target;
- image source-to-target = kernel connector;
- image connector = kernel relative-to-source;
- the separate (H^0/H^1_{rel}) initial cases.

Thus CA21.36 is closed for natural graded transports equipped with a linear
section.  Removing/synthesizing the section from weaker hypotheses is a
separate generalization, not part of this theorem statement.

### Exterior degree-two compatibility

`CubicalTwoFormBridge.lean` now closes the low-degree compatibility theorem
for exterior forms.  Every ordered causal two-cube determines exactly one
oriented concurrency diamond and vice versa.  Swapping the two cubical axes is
proved to be exactly reversal of that diamond.

Consequently the legacy skew law

[
eta(d^{op})=-eta(d)
]

is equivalent to the new cubical transposition law.  The source now constructs
a structural equivalence

[
C^2_{ext,cubical}simeq CausalTwoForm.
]

Together with the already-proved degree-zero and degree-one identifications,
the new exterior carrier genuinely extends the old 0--1--2 calculus rather
than replacing it with a parallel representation.

`CubicalSubsetGeometry.lean` additionally introduces intrinsic finite subsets
of cube axes, the configuration obtained after executing a whole selected
subset, and the selected/complementary factor cubes.  This is the geometry
needed for a robust subset-indexed proof of the Serre cup Leibniz law.

### Exterior low-degree complex

CubicalExteriorLowComplex.lean now defines linear exterior differentials

Omega_C^0 -> Omega_C^1 -> Omega_C^2.

The degree-zero map is exactly the raw cubical differential, since degree-one
alternation is vacuous. The degree-one map is constructed through the legacy

degree two and CausalTwoForm.

A comparison theorem proves that its underlying raw cubical cochain is exactly
CubicalCochain.differential 1. Therefore the already-proved arbitrary cubical
square-zero theorem yields d1 d0 = 0 immediately.

This closes the exterior differential in degrees 0--2. The remaining
all-degree theorem is that raw cubical d_n preserves the alternating submodule
for every n.

### Finite-dimensional real Hodge derivation

FiniteRealHodge.lean removes the abstract Hodge-representation hypothesis in a
precise positive sector. For a graded causal cochain complex whose degreewise
carriers are finite-dimensional real inner-product spaces, the codifferential
is defined to be the actual linear adjoint of d and the pairing is the real
inner product.

The source proves the energy identity

< x, Delta x > = ||d^* x||^2 + ||d x||^2,

hence harmonicity is equivalent to simultaneous closedness and coclosedness.
It also proves that the orthogonal complement of exact cochains is exactly the
kernel of the incoming codifferential.

Using orthogonal projection onto the exact subspace, every closed cochain is
then derived as exact + harmonic, and exact/harmonic intersection is trivial.
This constructs GradedCausalHodgeRepresentationSucc instead of assuming it.

Therefore CA21.43 is closed for the finite-dimensional real positive sector.
Complex Hermitian and indefinite variants remain separate generalizations.

### Full finite-real Hodge decomposition

FiniteRealHodgeDecomposition.lean upgrades the closed-cochain representation
to the full positive-degree decomposition.

Coexact cochains are defined intrinsically as range(d_(n+1)^*), and the source
proves this subspace is exactly the orthogonal complement of closed cochains.
It then proves the three pairwise orthogonality statements

exact ⟂ harmonic,
exact ⟂ coexact,
harmonic ⟂ coexact.

Orthogonal projection first splits an arbitrary cochain into closed + coexact;
the finite-real Hodge representation then splits the closed component into
exact + harmonic. Hence every cochain has

x = e + h + c

with e exact, h harmonic and c coexact.

A separate uniqueness theorem proves that any two such decompositions have
identical three components. Thus CA21.44 is a genuine orthogonal direct
decomposition theorem in the finite-dimensional real positive sector.

### Finite-real degree zero

FiniteRealHodgeZero.lean strengthens the degree-zero result. In the
finite-dimensional real inner-product sector, Delta_0 = d_0^* d_0 and the
standard adjoint kernel theorem gives ker(Delta_0)=ker(d_0). Thus harmonic
degree zero and H^0 coincide automatically and the degree-zero Hodge
representation is constructed without extra assumptions.

### Finite-real spectrum and Green operator

FiniteRealHodgeSpectrum.lean proves that every positive-degree causal Hodge
Laplacian in the finite-dimensional real sector is a positive symmetric
endomorphism. Mathlib's finite-dimensional spectral theorem therefore supplies
an orthonormal eigenbasis. The source records the ordered eigenvalues, proves
each eigenvalue is nonnegative, identifies the zero eigenspace with the causal
harmonic subspace, and identifies zero-eigenvalue multiplicity with harmonic
dimension.

FiniteRealHodgeGreen.lean then defines the Green operator spectrally: on a
Laplacian eigenvector of eigenvalue lambda it multiplies by lambda^{-1} when
lambda is nonzero, and sends the zero eigenspace to zero. In the same basis it
constructs the harmonic projector P_harm and proves

Delta G = G Delta = I - P_harm.

It also proves Delta P_harm = 0, G P_harm = 0, idempotence of P_harm, exact
range(P_harm)=Harmonic, fixed points of P_harm are precisely harmonic
cochains, and Green vanishes on the harmonic sector.

Thus CA21.46--47 are closed in the finite-dimensional real positive sector.
No infinite-dimensional Fredholm or regularized spectral claim is inferred;
those remain CA25 work.

### Optional invertible Phi/Psi spectral transport

PairedHodgeEquivalence.lean keeps invertibility outside the primitive paired
transport. A separate DegreewiseInverse property requires the two round trips
to be identities in each degree.

When that optional property is supplied, forward/backward naturality descends
to genuine linear equivalences on H0 and every positive cohomology group.
When the two Laplacian squares also commute, the same data induces a linear
equivalence of harmonic spaces and, for every scalar lambda, a linear
equivalence between the two lambda-eigenspaces. In finite-dimensional sectors
this proves equality of every eigenspace multiplicity.

Thus spectral preservation is now a derived theorem under explicit
invertibility/intertwining hypotheses; it is never inferred from the existence
of Phi/Psi alone.

### Finite coordinate mixed-tensor realization

CoordinateTensor.lean supplies the first fully concrete arbitrary-rank model
of the GeneralCausalTensorCalculus interface. For a finite index type iota, a
(p,q)-tensor is represented by its complete component table on p
contravariant and q covariant index tuples.

The implementation provides:

- bilinear tensor product by concatenating both index blocks;
- contraction of the final contravariant/covariant slot pair by finite
  diagonal summation;
- independent contravariant and covariant slot permutations as linear
  equivalences;
- zero and identity-permutation regression laws.

This gives a finite computational/formal model for all tensor ranks and is a
useful oracle for the intrinsic theory. CA21.57 remains open because it asks
for a basis-independent TensorProduct realization and a theorem relating that
intrinsic carrier to this coordinate model.

### Torsion, Koszul and causal Levi-Civita uniqueness

The local linearized geometry now contains the missing soldering layer.

A `CausalSolderForm` realizes every enabled event direction as a vector in
the local fiber.  A `CausalDirectionBracket` records an explicit
antisymmetric bracket, with a zero-bracket realization for commuting causal
coordinates.

For a local gauge potential A, torsion is

T_A(d,e) = A_d theta(e) - A_e theta(d) - B(d,e).

Infinitesimal metric compatibility is stated independently as skew-adjointness
